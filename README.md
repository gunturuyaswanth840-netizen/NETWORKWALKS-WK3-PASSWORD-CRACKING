# Week 3 – Password Cracking

## Project Overview

This project was completed as part of the **NETWORKWALKS Week 3 Cybersecurity Project**.

I completed both required modules:

- **W3-PM1 – Password Cracking with JTR**
- **W3-PM2 – Password Cracking with NW Tools**

## Tools Used

- John the Ripper (JTR)
- Johnny
- NetworkWalks Password Cracker
- Wordlist

## W3-PM1 – Password Cracking with JTR

Used **John the Ripper and Johnny** to perform password recovery on a protected PDF in the provided lab environment.

**Result:** Password successfully recovered and the PDF was unlocked.

## W3-PM2 – Password Cracking with NW Tools

Used the **NetworkWalks Password Cracker** with the provided password hash and built-in password list.

**Result:** Password successfully recovered.

## What I Learned

- How password hashes are used during password recovery.
- How dictionary-based password cracking works.
- How to use John the Ripper and Johnny.
- The importance of strong and unique passwords.
